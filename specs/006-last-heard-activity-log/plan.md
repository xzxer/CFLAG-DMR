# Implementation Plan: F9 — Last-Heard & Activity Log

**Branch**: `006-lastheard-log` | **Date**: 2026-05-25 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/006-last-heard-activity-log/spec.md`

---

## Summary

Admin and public users can view a live feed of DMR transmission activity read directly from the HBMonv2 `lastheard.log` CSV file. Public visitors see the last 20 entries (toggleable via `system_settings`). Authenticated users see the full history with callsign/talkgroup/date filters and 50-row pagination. The admin dashboard gains a compact Last Heard card (last 5 entries) for system_admins.

No new database tables. Data flows: `lastheard.log` → `app/lastheard/reader.php` → `public/last-heard.php`.

---

## Technical Context

**Language/Version**: PHP 8.3 — `declare(strict_types=1)` in all new files

**Primary Dependencies**: None — plain PHP, SplFileObject for efficient tail reads, PDO for system_settings lookups (existing infrastructure)

**Storage**: No new tables. Two new rows in existing `system_settings` table via migration 007.

**Testing**: Manual verification via quickstart.md scenarios. No automated tests requested.

**Target Platform**: Apache on Ubuntu 24.04; `public/` is document root

**Performance Goals**: Page load < 3s for any log size up to 1 year of typical DMR activity (~50k lines). Public view reads only the file tail (last ~500 lines); authenticated view reads all lines but paginates to 50 rows per page.

**Constraints**: No new Composer dependencies. No JS libraries. `www-data` read access to `/opt/HBMonv2/log/lastheard.log` — confirmed world-readable (0644) without any `chown` needed.

## Key Technical Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Data source | Direct CSV file read | No DB ingestion for MVP; HBMonv2 log is the live truth |
| Large file read (public) | SplFileObject tail read | Avoids loading unbounded file into memory for 20-row public view |
| Large file read (auth) | `file()` + reverse + filter | All rows needed for filter matching; pagination limits browser payload |
| Auto-refresh (public) | `<meta http-equiv="refresh" content="30">` | Zero JS, universally supported |
| Auto-refresh (auth) | `setTimeout(() => location.reload(), 30000)` | Preserves GET filter params on reload |
| Filter submission | GET form | Filter state preserved in URL across pagination and auto-refresh |
| Talkgroup filter | Accepts numeric ID or name text | Flexible; numeric → match stripped TG column; text → substring of tg_name |
| Path security | LASTHEARD_ALLOWED_DIRS constant | Same pattern as F8; hardcoded, not DB-configurable |
| Missing log file | Treat as empty (not error) | Normal on fresh server before first transmission |

// PDO query: SELECT value FROM system_settings WHERE key = ?

function validate_lastheard_path(string $path): string|false
// realpath($path) then check each LASTHEARD_ALLOWED_DIRS prefix

function parse_lh_line(string $line): array|null
// str_getcsv($line) → must be 12 fields
// Strip 'TS' from [7], 'TG' from [8]
// Validate strtotime($row[0]) is not false
// Return assoc array with keys: datetime, duration, call_type, action,
//   system_name, src_id, callsign, timeslot, tgid, tg_name, sub_id, short_name

function load_lastheard(int $limit = 0, int $offset = 0, array $filters = []): array
// Returns: ['rows' => LhEntry[], 'total' => int, 'error' => string|null]
// File not found → return ['rows'=>[], 'total'=>0, 'error'=>null]
// File unreadable → return ['rows'=>[], 'total'=>0, 'error'=>'Activity log is currently unavailable.']
// For public (small limit, no filters): use SplFileObject tail read
// For authenticated (filters): use file() + array_reverse() + filter loop + array_slice()
// Filter keys: 'callsign' (substr match on [6]), 'tg' (numeric→[8] or text→[9]),
//              'date_from' (strtotime), 'date_to' (strtotime)

## Page: `public/last-heard.php`

**Auth logic**:
```php
start_session();
$is_authed = isset($_SESSION['user_id']);
$public_enabled = (bool)(int) get_lastheard_setting('public_lastheard_enabled');

if (!$is_authed && !$public_enabled) {
    header('Location: /login.php');
    exit;
}
```

**Load logic**:
```php
if ($is_authed) {
    // Parse GET filters
    $filters = [
        'callsign'  => trim($_GET['callsign'] ?? ''),
        'tg'        => trim($_GET['tg'] ?? ''),
        'date_from' => trim($_GET['date_from'] ?? ''),
        'date_to'   => trim($_GET['date_to'] ?? ''),
    ];
    $page   = max(1, (int)($_GET['page'] ?? 1));
    $offset = ($page - 1) * 50;
    $result = load_lastheard(50, $offset, array_filter($filters));
} else {
    $result = load_lastheard(20);
}
```

**Render**:
- Title: "Last Heard — CFLAG DMR"
- If `$result['error']` → show error div
- Else if `$result['rows']` empty → show "No activity recorded yet"
- Else → table with columns: Date/Time, Callsign, DMR ID, TG Name, TG ID, Slot, System, Duration
- All cell values via `htmlspecialchars($val, ENT_QUOTES, 'UTF-8')`
- Auth view only: filter `<form method="get">` above table, pagination nav below
- Auto-refresh: meta tag (public) or JS setTimeout (auth)
- Nav link: `← Home` or `← Dashboard` (if authed)

## Implementation Notes

- `load_lastheard()` MUST handle the file not existing without returning an error (normal on fresh server)
- For the public tail read: use `SplFileObject` seeking — avoids loading tens of thousands of lines into PHP memory
- The filter form uses GET so the URL remains bookmarkable and auto-refresh works without AJAX
- Pagination: `ceil($result['total'] / 50)` gives total pages; current page is `max(1, (int)$_GET['page'])`
- Duration display: `round((float)$row['duration']) . 's'` — no decimal places needed
- TG filter: if `ctype_digit($filter_tg)` → compare against `$row['tgid']`; else → `stripos($row['tg_name'], $filter_tg)`
- The `<meta refresh>` tag MUST be inside `<head>` for public view; JS reload for auth view is in `<script>` at bottom of body
