# Implementation Plan: F8 — HBLink Config Visibility

**Branch**: `005-hblink-config-view` | **Date**: 2026-05-25 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/005-hblink-config-visibility/spec.md`

## Summary

Add three read-only admin pages and a dashboard card that let `system_admin` users view the live HBLink configuration file (`hblink.cfg`), routing rules file (`rules.py`), and process status — without SSH access. File paths and process name are read from `system_settings` and validated against a hardcoded base-directory allowlist before use. Sensitive INI values (passphrase/password/secret keys) are masked in the UI with a JS-only "Show" toggle. A warning banner appears when the config file has been modified since HBLink started.

## Key Implementation Decisions

### Path validation (FR-011)
File paths are read from `system_settings`, then validated with `realpath()` against a hardcoded `HBLINK_ALLOWED_DIRS` constant in `app/hblink/reader.php`. If `realpath()` returns false (file doesn't exist) or the resolved path doesn't start with an allowed directory, the function returns an error string — no file read occurs.

```php
const HBLINK_ALLOWED_DIRS = ['/opt/hblink3/', '/etc/hblink/', '/opt/hblink/'];
```

### INI masking (FR-002, FR-003)
Use regex on the raw file string — do NOT use `parse_ini_file()`, which would lose comments and formatting. Pattern: for each line matching `key = value` or `key=value`, if the key matches `/^(PASSPHRASE|PASSWORD|SECRET)$/i`, wrap the value in a `<span class="masked-value" data-val="...">` with the masked display. The actual value is stored in `data-val`; a vanilla-JS `toggleMask()` function swaps the display. This is acceptable per the spec's security model (system_admin already has full server access).

### Process start time (FR-009)
PID resolution: try reading `hblink_pid_path` from system_settings first; fall back to `shell_exec('pgrep -f ' . escapeshellarg($process_name))` (first line). Once PID is known, read `/proc/{pid}/stat`, split on whitespace, take field index 21 (0-based — the `starttime` field). Convert: `boot_time + starttime / CLK_TCK`. Boot time comes from `/proc/stat` line starting with `btime`. CLK_TCK is typically 100 on Linux (use `posix_sysconf(2)` or default 100).

### Config-drift warning (FR-005)
Compare `filemtime($cfg_path)` to the process start time (epoch seconds). If `filemtime > start_time`, show the warning banner.

### Line-numbered code display
Render file content as an `<ol>` where each `<li>` is one line. CSS removes the default list style and adds monospace font, dark background. On mobile the block scrolls horizontally via `overflow-x: auto` on a wrapping `<div>`.
