# Implementation Plan: F6 — Talkgroup Management

**Branch**: `008-talkgroup-management` | **Date**: 2026-05-26 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/008-talkgroup-management/spec.md`

## Summary

Admins manage the canonical network talkgroup catalog. Users can request new talkgroups and manage owned ones. Ownership tiers (admin / user_partial / user_full) control edit rights. The talkgroup catalog is the data foundation for device subscriptions (F5 US4, via migration 010) and HBLink routing rules (F7). Migration 009 ships all four F6 tables; migration 010 ships the join table that requires both F5 (devices) and F6 (talkgroups).

## Technical Context

**Language/Version**: PHP 8.3 — `declare(strict_types=1)` in all source files

**Primary Dependencies**: PDO/MariaDB (existing), `app/auth/` (existing), `app/database/` (existing)

**Storage**: MariaDB — migrations 009 (`talkgroups`, `talkgroup_requests`, `talkgroup_access_lists`, `talkgroup_ownership_upgrade_requests`) and 010 (`device_talkgroup_subscriptions`)

**Testing**: Manual verification per quickstart.md — no automated tests

**Target Platform**: Apache/PHP on Ubuntu 24.04; `public/` is document root

**Project Type**: Web application (server-side rendered PHP)

**Performance Goals**: Standard — talkgroup catalog is O(100s) of rows; no pagination required for MVP

**Constraints**: CSRF on all POST forms; `htmlspecialchars` on all rendered user input; PDO prepared statements; deny-wins access control for user_full talkgroups

**Scale/Scope**: Small network, O(100) talkgroups; admin-managed catalog with user ownership for select talkgroups

### User Page: `public/user/talkgroups.php`

```
require_once app/auth/roles.php
require_once app/talkgroups/manager.php
start_session()
require_login()

Handle POST actions:
  action=request     → validate → submit_talkgroup_request()
  action=edit_owned  → validate → update_talkgroup() (ownership check inside)
  action=add_access  → add_access_entry() (user_full check)
  action=remove_access → remove_access_entry()
  action=request_upgrade → submit_ownership_upgrade()

$my_talkgroups = SELECT talkgroups WHERE owner_user_id = $user_id
$my_requests   = get_user_talkgroup_requests($user_id)

Render sections:
  1. "My Talkgroups" — list of owned talkgroups with edit form and access list (user_full only)
  2. "My Requests" — list of submitted talkgroup requests with status
  3. "Request a New Talkgroup" form
```

### Admin Pages: `public/admin/talkgroups/`

**`index.php`** — Talkgroup Catalog Management

```
require_role('system_admin')

  action=create  → create_talkgroup()

  action=enable  → set_talkgroup_active(true)
  action=delete  → delete_talkgroup()

Render:
  - Search/filter bar
  - Talkgroup table: TGID | Name | Type | Owner | Tier | Status | Actions

```

**`requests.php`** — Talkgroup Request Queue

```
require_role('system_admin')

Handle POST:
  action=approve → approve_talkgroup_request() with final_tgid and tier
  action=deny    → deny_talkgroup_request()

$pending = get_pending_talkgroup_requests()

Render:
  - Pending requests table: User | Proposed TGID | Name | Type | Description | Date | Actions

```
