# Implementation Plan: Admin Login

**Branch**: `001-admin-login` | **Date**: 2026-05-24 | **Spec**: feature description in user message

**Input**: Feature specification provided directly; research resolved in `specs/001-admin-login/research.md`

## Summary

Build a secure admin login foundation for CFLAG DMR using plain PHP, MariaDB, and Apache. Implements
credential verification, session management, CSRF protection, and a protected admin dashboard shell
that establishes the reusable authentication pattern for all future admin-only pages.

## Technical Context

**Language/Version**: PHP 8.x — `declare(strict_types=1)` in all source files (established by `public/index.php`)

**Primary Dependencies**: None (zero Composer packages). PDO and pdo_mysql PHP extensions (already present on server).

**Storage**: MariaDB via PDO. Single table: `admin_users`. PHP native file-backed sessions.

**Testing**: Manual test plan (see below). No automated test framework in scope for this slice.

**Target Platform**: Linux server, Apache, HTTP (dev). Future: HTTPS production.

**Project Type**: Server-rendered web application (plain PHP, no framework).

**Performance Goals**: N/A for an admin panel with a small number of concurrent users.

**Constraints**: Zero new Composer dependencies. Apache document root is `public/` only. Secrets must stay in `.env`.

**Scale/Scope**: Single admin panel, small number of admin accounts, low traffic.

## File-by-File Responsibility Breakdown

### `migrations/001_create_admin_users_table.sql`
- Creates `admin_users` table with all columns.
- Sets `VARCHAR(255)` on `password_hash` to accommodate bcrypt and future algorithms.
- Sets `UNIQUE` on `username`.
- Sets `is_active TINYINT(1) NOT NULL DEFAULT 1`.
- Sets `last_login_at DATETIME NULL` (null until first login).
- Sets `created_at` and `updated_at` with appropriate defaults.
- **Does not** seed any rows (seeding is a manual step in the quickstart).

### `app/config/env.php`
- Reads `.env` from the project root (one level above `public/`).
- Parses `KEY=VALUE` pairs. Strips surrounding single/double quotes from values.
- Ignores blank lines and lines starting with `#`.
- Populates `$_ENV` and/or an internal array.
- Exposes `env(string $key, mixed $default = null): mixed` helper.
- Throws a clear error if `.env` is missing (fail fast in dev; misconfiguration should surface immediately).

### `app/database/connection.php`
- Requires `app/config/env.php`.
- Creates and returns a PDO instance using `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS` from env.
- DSN charset: `utf8mb4`.
- PDO attributes: `ERRMODE_EXCEPTION`, `FETCH_ASSOC`, `EMULATE_PREPARES => false`.
- Exposes a `get_db(): PDO` function (or equivalent simple factory — not a class unless needed).

### `app/auth/session.php`
- Requires `app/config/env.php`.
- Defines `start_session(): void` — configures cookie params then calls `session_start()`.
  - Cookie params: `httponly=true`, `samesite=Strict`, `secure` from `SESSION_SECURE_COOKIE` env var.
- Defines `csrf_token(): string` — generates token on first call, returns existing token on subsequent calls.
- Defines `verify_csrf(string $token): bool` — `hash_equals()` comparison.
- Defines `is_admin(): bool` — checks `$_SESSION['admin_id']` is set and is an int.
- Defines `require_admin(): void` — calls `is_admin()`, redirects to `/login.php` and exits if false.
- Defines `redirect(string $url): never` — sets `Location` header and exits.

### `app/auth/login.php`
- Requires `app/database/connection.php`.
- Defines `attempt_login(string $username, string $password): bool`.
  - Queries `admin_users` by username using a prepared statement.
  - If no row found: returns false (timing-safe — does not short-circuit before `password_verify`).
  - If `is_active = 0`: returns false.
  - Calls `password_verify($password, $row['password_hash'])`.
  - On success: calls `session_regenerate_id(true)`, populates `$_SESSION` with `admin_id`, `admin_username`, `admin_display_name`, `authenticated_at`, updates `last_login_at` via prepared statement, returns true.
  - On failure: returns false.

### `public/login.php`
- Requires `app/auth/session.php`, then calls `start_session()`.
- If `is_admin()`: redirects to `/admin/`.
- On GET: renders login form with `csrf_token()` in a hidden field.
- On POST: validates CSRF with `verify_csrf($_POST['csrf_token'] ?? '')`.
  - CSRF failure or missing fields → show generic error, re-render form.
  - Calls `attempt_login($_POST['username'], $_POST['password'])`.
  - Success → redirect to `/admin/`.
  - Failure → show generic error, re-render form.
- All user output escaped with `htmlspecialchars(..., ENT_QUOTES, 'UTF-8')`.
- Links `public/assets/css/app.css`.

### `public/logout.php`
- Requires `app/auth/session.php`, then calls `start_session()`.
- Clears `$_SESSION`, calls `session_destroy()`, clears session cookie.
- Redirects to `/login.php`.

### `public/admin/index.php`
- Requires `app/auth/session.php`, then calls `start_session()`.
- Calls `require_admin()` before any output.
- Renders dashboard: shows `$_SESSION['admin_display_name']` (fallback to `admin_username`).
- Includes logout link to `/logout.php`.
- Links `public/assets/css/app.css`.
- All session values escaped before output.

## Database Schema

```sql
CREATE TABLE admin_users (
    id              INT UNSIGNED    NOT NULL AUTO_INCREMENT,
    username        VARCHAR(64)     NOT NULL,
    password_hash   VARCHAR(255)    NOT NULL,
    display_name    VARCHAR(128)    NOT NULL,
    is_active       TINYINT(1)      NOT NULL DEFAULT 1,
    last_login_at   DATETIME            NULL DEFAULT NULL,
    created_at      DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP
                                             ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (id),
    UNIQUE KEY uq_username (username)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

**Notes**:
- `password_hash VARCHAR(255)`: bcrypt produces 60-char hashes; 255 chars provides room for future algorithm upgrades (Argon2id hashes are longer).
- `is_active`: 0 = disabled. Account persists; login is blocked at the application layer.
- `last_login_at NULL`: null until the admin logs in at least once.
- Engine `InnoDB` for transaction support and referential integrity capability in future features.

## Manual Test Plan

**Preconditions**: Migration applied. Initial admin user created. Apache serving `public/`. `.env` has `SESSION_SECURE_COOKIE=false`.

1. **Apply migration**: Run `mysql ... < migrations/001_create_admin_users_table.sql`. Confirm `admin_users` table exists with all columns.

2. **Create initial admin user**: Run the PHP hash command and INSERT as shown in Migration Instructions. Confirm `SELECT * FROM admin_users;` returns one row.

3. **Unauthenticated access to /admin/**: Visit `http://<dev>/admin/` while logged out. Confirm HTTP redirect to `/login.php`. Confirm no session data present.

4. **Bad credentials**: On `/login.php`, submit an incorrect username or password. Confirm the page re-renders with exactly: `"Invalid username or password."`. Confirm no detail about whether the username exists.

5. **Valid credentials**: Submit correct username and password. Confirm HTTP redirect to `/admin/`. Confirm `$_SESSION` contains `admin_id`, `admin_username`, `admin_display_name`, `authenticated_at`.

6. **Protected dashboard**: Confirm `/admin/` renders with the admin's display name. Confirm logout link is present.

7. **Logout**: Click logout (or visit `/logout.php`). Confirm redirect to `/login.php`. Confirm session data is destroyed (PHP session file removed or cookie invalidated).

8. **Post-logout access**: Visit `/admin/`. Confirm redirect to `/login.php`. Confirm no privileged content rendered.

9. **PHP syntax check**: Run `php -l` against all new files. All must report `No syntax errors detected`.

10. **Apache error log**: Run `sudo tail -50 /var/log/apache2/error.log`. Confirm no PHP fatal errors or warnings related to this feature.

**CSRF test (bonus)**:
- Load `/login.php`, extract the CSRF token from the form source.
- Manually POST to `/login.php` with a tampered or missing `csrf_token`.
- Confirm generic error is shown and login is rejected.
